# TradeFlow Money Manager

A Streamlit web app for dynamic per-trade percentage money management.

## Features
- Initial capital
- Per-trade percentage
- Win return percentage
- Dynamic next-trade calculation from updated capital
- WIN / LOSS buttons
- Live capital, P/L, win rate, trade count
- Trade history with before/after capital
- Save settings to JSON
- Clear trades
- Full reset

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
